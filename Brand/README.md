# Brand

The icon and logos in this folder are generic drawings made for this project: a fader knob
with a scale lit up to 7.0, the reference level of a cinema processor. They are not Dolby
logos. The same files ship with the integration in `custom_components/dolby_cp750/brand/`
so Home Assistant and HACS show an icon.

You may replace them with your own images. Dolby is a trademark of Dolby Laboratories; this
project is not affiliated with or endorsed by Dolby Laboratories.
